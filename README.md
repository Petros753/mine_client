# Booking Platform — MVP (аналог YCLIENTS)

## Стек
- Next.js 16 (App Router) + TypeScript + Tailwind CSS
- Prisma ORM + PostgreSQL
- NextAuth v5 (Auth.js) — авторизация по email и паролю
- Resend — email-уведомления

## Как запустить локально

1. Установи зависимости:
   ```bash
   npm install
   ```

2. Подними PostgreSQL. Проще всего — через Docker:
   ```bash
   docker run --name booking-db -e POSTGRES_PASSWORD=password -e POSTGRES_DB=booking_platform -p 5432:5432 -d postgres:16
   ```

3. Скопируй `.env.example` в `.env` и заполни переменные:
   - `DATABASE_URL` — строка подключения к PostgreSQL (если меняешь пароль/порт в Docker-команде выше, поправь и здесь);
   - `AUTH_SECRET` — секрет для подписи сессии, обязателен. Сгенерировать: `npx auth secret`;
   - `RESEND_API_KEY` — ключ Resend. Без него письма не отправляются, а печатаются в консоль сервера — для локальной разработки этого достаточно;
   - `EMAIL_FROM` — адрес отправителя писем.

4. Сгенерируй клиент Prisma и накати схему на базу:
   ```bash
   npx prisma generate
   npx prisma db push
   ```

5. Залей демо-данные (компания, филиал, услуги, мастера, записи на сегодня):
   ```bash
   npm run seed
   ```
   Демо-владелец для входа: `owner@example.com` / `demo1234`.

6. (Опционально) Открой визуальный редактор базы:
   ```bash
   npx prisma studio
   ```

7. Запусти проект:
   ```bash
   npm run dev
   ```
   Открой http://localhost:3000

## Структура проекта

```
prisma/schema.prisma   — схема базы данных
src/app/                — страницы и роуты (Next.js App Router)
src/lib/                — вспомогательные модули (БД, авторизация, письма)
src/components/         — переиспользуемые компоненты
src/proxy.ts            — защита /admin/* и /dashboard (в Next.js 16 middleware называется proxy)
```

## Основные разделы

| Путь | Назначение | Доступ |
| --- | --- | --- |
| `/book/[branchId]` | Публичный виджет онлайн-записи | всем |
| `/register`, `/login` | Регистрация компании и вход | всем |
| `/dashboard` | Дашборд с ключевыми метриками | по сессии |
| `/admin` | Админ-панель | по сессии |
| `/admin/appointments` | Журнал записей: фильтры и смена статусов | по сессии |
